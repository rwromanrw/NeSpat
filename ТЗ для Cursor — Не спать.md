# ТЗ: приложение «Не спать» (NeSpat) для строки меню macOS

Рабочая папка проекта: `/Users/rw/Desktop/Vibe code/Не спать`
Mac: MacBook Air, Apple M5, 16 ГБ, macOS 27.2 (26B123), Xcode установлен, Swift 6.4.
Язык интерфейса: русский.

## 1. Цель
Маленькое нативное приложение в строке меню. Оно:
- показывает температуру, загрузку процессора и занятую память;
- по кнопке «Не спать» не даёт Mac уснуть, в том числе с закрытой крышкой, чтобы Cursor продолжал работать;
- честно показывает, включён режим или нет: «включено» только после того, как система это подтвердила.

## 2. Решения владельца (не менять без согласования)
1. В строке меню: значок сна + температура + загрузка CPU + память, компактно, например `☕ 52° 18% 11 ГБ`. Чашка = не спит, луна = обычный сон, `⚠` = состояние неизвестно.
2. Обновление цифр: каждые 5 секунд.
3. Клик по значку открывает окно (SwiftUI `MenuBarExtra`, стиль `.window`) с кнопкой и подробностями.
4. Длительность: без ограничения / 1 ч / 3 ч / 8 ч.
5. Обычный сон возвращается автоматически при:
   - перегреве;
   - заряде ниже 15% на батарее;
   - выходе или падении приложения (через отдельный сторож).
6. При закрытии крышки во время режима гасить экран.
7. Права: узкое правило sudoers, пароль вводится один раз.
8. Без автозапуска при входе в систему. Ничего постоянного не ставить без явного согласия владельца.
9. Без сети, без телеметрии, без проверки обновлений, без платных компонентов. Без значка в Dock (`LSUIElement`).

## 3. Окно по клику
- Большой переключатель «Не спать» и строка статуса:
  - «Включено — подтверждено системой»;
  - «Выключено — обычный сон»;
  - «⚠ Не удалось подтвердить» (с подсказкой, что делать).
- Выбор длительности; при таймере — оставшееся время.
- Процессор: температура (или «—», если датчик недоступен) и загрузка в процентах.
- Память: занято / всего, цветная полоска нагрузки (зелёный / жёлтый / красный).
- Батарея: процент и «на зарядке / от батареи».
- Причина последнего автоотключения (например, «Сон возвращён: заряд 14%»).
- «Настроить права» — если правило sudoers не установлено.
- «Выход» — возвращает обычный сон, если режим включило наше приложение.

## 4. Механика сна (критично)
- Включение: `/usr/bin/sudo -n /usr/bin/pmset -a disablesleep 1`; выключение: тот же вызов с `0`. Запускать через `Process` с фиксированным массивом аргументов, без shell.
- `caffeinate` / IOPMAssertion закрытую крышку НЕ держат, ими это не заменять.
- Чтение состояния после каждой записи и периодически:
  1. `pmset -g` → строка `SleepDisabled 1/0`;
  2. запасной вариант: `ioreg -r -d 1 -c IOPMrootDomain` → `"SleepDisabled" = Yes/No`.
  На macOS 27 строка в `pmset -g` может отсутствовать (известный баг LidAwake #1). Отсутствие строки после нашей записи НЕ считать «выключено» → показывать `⚠`.
- Крышка: `AppleClamshellState` из `ioreg` (IOPMrootDomain). При переходе в «закрыта» во время режима → `pmset displaysleepnow` (root не нужен).
- Флаг `SleepDisabled` глобальный и НЕ снимается при выходе или падении приложения; возможно, он сохраняется и после перезагрузки (источники противоречат). На это не полагаться.
- Приложение снимает флаг только если сессию включило оно само (файл-признак «наша сессия»). Чужой флаг не трогать молча: показать «Сон выключен не этим приложением» и предложить вернуть сон кнопкой.
- ВАЖНО: сейчас на этом Mac уже стоит `SleepDisabled 1` (остался после ручной команды). Приложение должно корректно это показать.

## 5. Права администратора
- Одноразовая установка файла `/etc/sudoers.d/ne-spat` (владелец root:wheel, права 0440, проверка `visudo -cf` до установки), ровно одна строка:
  `<логин> ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 0, /usr/bin/pmset -a disablesleep 1`
  Без wildcard, логин через `id -un`, не root.
- Установка по кнопке «Настроить права» через `osascript ... with administrator privileges` — пароль вводит владелец.
- `uninstall` удаляет правило и всё остальное.
- НЕ использовать AppleScript для управления Finder или другими приложениями. НЕ делать снимки экрана (`screencapture`). НЕ вызывать `sfltool` и другие команды, требующие пароля, кроме установки правила по кнопке.

## 6. Сторож (watchdog)
- Минимальный LaunchAgent пользователя (или режим `--watchdog` того же бинарника), устанавливается только вместе с правами и с согласия владельца.
- Каждые 15–30 с: если есть признак «наша сессия», а приложение не запущено → вернуть сон. Также следит за таймером, зарядом 15% и перегревом, пока крышка закрыта.
- Логи — в `~/Library/Logs/NeSpat/`, не в `/tmp`.
- Это не автозапуск приложения: сторож только возвращает сон.
- Проверить на живом Mac, что сторож действительно срабатывает при закрытой крышке.

## 7. Метрики
- Температура на Apple Silicon без sudo: IOHIDEventSystemClient (закрытый API, через dlsym, как в Stats / mac-temp), датчики PMU/SoC. На M5 набор датчиков может отличаться; если «температуры CPU» нет — показать общую температуру чипа с пометкой или «—». `powermetrics` не использовать (нужен root).
- Загрузка CPU: `host_processor_info` (разница между замерами).
- Память: `host_statistics64` (занято = active + wired + compressed) и `hw.memsize`; цвет полоски — по уровню давления памяти.
- Батарея: IOPowerSources (`IOPSCopyPowerSourcesInfo`), не парсить текст `pmset -g batt` (зависит от локали).
- Перегрев: `ProcessInfo.thermalState` ≥ `.serious` → вернуть сон; плюс порог температуры, если датчик доступен (порог согласовать, предложить ~95 °C).
- Нагрузка от самого приложения: минимальная, таймер 5 с, без лишних перерисовок.

## 8. Сборка и поставка
- Swift Package или проект Xcode + `scripts/build.sh` (ad-hoc подпись `codesign -s -`), `scripts/uninstall.sh`, `README.md` на русском.
- Приложение ставится в `~/Applications/NeSpat.app` (или по выбору владельца).
- Режим `--print-stats` для проверки из Терминала: печатает температуру, загрузку, память, батарею, состояние сна и крышки.

## 9. Приёмка (все пункты проверить на этом Mac)
1. Сборка без ошибок и предупреждений Swift 6.
2. `--print-stats` даёт правдоподобные значения; температура либо есть, либо честно «—».
3. В строке меню цифры обновляются раз в 5 с; нагрузка самого приложения < 1% CPU в покое.
4. Без правила sudoers кнопка не изображает «включено», а предлагает настроить права.
5. После включения `pmset -g` (или `ioreg`) подтверждает `SleepDisabled 1`, а индикатор — «подтверждено».
6. Тест крышки: включить, закрыть крышку на 10 минут без внешнего монитора; Cursor продолжал работу, экран погас. Проверить, вернулся ли Wi‑Fi после открытия.
7. Таймер 1 ч (для теста допустим скрытый тестовый 2 мин) возвращает сон.
8. Убить приложение (`kill -9`) → сторож возвращает сон в течение 30 с.
9. «Выход» возвращает сон; чужой флаг молча не снимается.
10. `uninstall.sh` удаляет приложение, сторож, правило sudoers, файлы в Application Support и Logs; после удаления `SleepDisabled 0`.

## 10. Справка
- Непроверенный черновик предыдущей попытки: `~/Developer/NeSpat` (там же сборка `build/NeSpat.app`, данные в `~/Library/Application Support/NeSpat` и `~/Library/Logs/NeSpat`). Его можно смотреть как справку, но не доверять: он не прошёл ревью. После переноса — удалить с согласия владельца.
- Похожие открытые проекты для справки: Sleepless (Aboudjem), LidAwake (TurboKach), Lidless (nghialuong), Stats (exelban) — для чтения температуры.
- Предупреждение: не класть работающий Mac в сумку; у Air нет вентилятора.

## 11. Порядок работы
Сначала план и список файлов → согласовать с владельцем. Потом код и сборка. Права администратора и сторож ставить только после явного «да». Каждый пункт приёмки отмечать фактическим результатом, без «должно работать».
