# Не спать (NeSpat)

Маленькое приложение в строке меню для macOS (Apple Silicon). Показывает температуру чипа, загрузку CPU и память, а по кнопке «Не спать» не даёт Mac уснуть, в том числе с закрытой крышкой.

Без сети, без телеметрии, без автозапуска приложения, без значка в Dock.

## Строка меню

- `☕ 52° 18% 69%` — режим включён и подтверждён системой
- `52° 18% 69%` — обычный сон
- `⚠ …` — состояние не удалось подтвердить

Цифры: температура чипа (max по датчикам PMU tdie), загрузка CPU, занятая память в процентах. Обновление раз в 5 секунд.

## Как держит без сна

Одной системной настройкой: `sudo -n /usr/bin/pmset -a disablesleep 1` (выключить — то же с `0`). Это единственный способ, который переживает закрытие крышки; `caffeinate` и power assertions крышку не держат.

После каждой записи приложение проверяет результат у системы (`IOPMrootDomain.SleepDisabled` через IOKit, запасной вариант — `pmset -g`) и только тогда показывает «Включено». При закрытии крышки во время режима экран гасится командой `pmset displaysleepnow`.

## Права

При каждом включении режима macOS показывает системный диалог «Введите пароль администратора» (если пароль не закэширован в этой сессии sudo). Постоянных правил sudoers приложение не создаёт: сначала пробует `sudo -n`, и только если это не удалось — спрашивает пароль через системный диалог. Отмена диалога = режим не включается, статус остаётся честным.

Флаг `SleepDisabled` глобальный и сохраняется в системных настройках питания: он не снимается сам при выходе или падении приложения и переживает перезагрузку. Поэтому:

- приложение снимает флаг только если сессию включило оно само;
- если флаг включён не этим приложением, панель честно пишет «Сон выключен не этим приложением» и предлагает кнопку «Вернуть обычный сон»;
- сторож (см. ниже) возвращает сон, если приложение упало.

Не кладите работающий Mac в сумку: у Air нет вентилятора, а с выключенным сном машина продолжает работать и греться. Держите нормальную вентиляцию (см. рекомендации Apple по температуре).

## Автоотключение (возврат обычного сна)

- кончился выбранный срок (без ограничения / 1 ч / 3 ч / 8 ч);
- батарея ниже 15% при питании от батареи;
- перегрев: `thermalState ≥ serious` или температура чипа ≥ 95 °C;
- нажатие «Выход» (если сессию включило это приложение);
- падение приложения — через сторожа.

Причина последнего автоотключения показывается в панели, например: «Сон возвращён: заряд 14%».

## Сторож

`scripts/install-watchdog.sh` ставит LaunchAgent `local.nespat.watchdog`: каждые 30 секунд короткий проход того же бинарника (`--watchdog`). Правила:

1. сессия наша, а приложение не запущено → вернуть сон (покрывает крах и истёкший таймер);
2. сессия наша и (батарея < 15% от батареи ИЛИ тепловой режим ≥ serious) → вернуть сон (страховка от зависшего процесса).

Это не автозапуск приложения: сторож ничего не включает, только возвращает сон. Журнал: `~/Library/Logs/NeSpat/watchdog.log`.

## Сборка и установка

```bash
./scripts/build.sh --install     # сборка + ~/Applications/NeSpat.app
open ~/Applications/NeSpat.app
```

Проверка без GUI:

```bash
~/Applications/NeSpat.app/Contents/MacOS/NeSpat --print-stats
```

Тестовый таймер 2 минуты для приёмки: запустить с `--test-timer` (в панели появится пункт «2 мин (тест)»).

## Передача другим (DMG)

Собрать диск-образ для установки на другой Mac:

```bash
./scripts/package-dmg.sh
```

Результат: `build/NeSpat-1.0.dmg` (~1,5 МБ). Откройте на Mac → перетащите `NeSpat.app` в Applications → при первом запуске: правый клик → Открыть (ad-hoc подпись). Пароль администратора спрашивается при включении режима «Не спать».

Сторож на чужом Mac ставится отдельно из исходников (`scripts/install-watchdog.sh`), если нужен.
## Удаление

```bash
./scripts/uninstall.sh            # приложение, сторож, sudoers, файлы; сон — если сессия наша
./scripts/uninstall.sh --force-sleep  # то же + гарантированно вернуть сон
```

## Данные

- Состояние сессии: `~/Library/Application Support/NeSpat/session.json`
- Журнал сторожа: `~/Library/Logs/NeSpat/watchdog.log`

## Замечания по метрикам

- Температура читается через частный API IOHID (датчики PMU tdie), как в открытом проекте Stats. Это температура кристалла, а не корпуса; сторонние датчики не предназначены для диагностики железа. Если на вашей ревизии чипа датчиков нет — показывается «—».
- CPU — `host_processor_info` (дельта замеров), память — `host_statistics64` (active + wired + compressed), батарея — IOPowerSources.
