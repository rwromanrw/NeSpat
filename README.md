# Не спать (NeSpat)

Небольшое приложение для строки меню macOS.

**Зачем.** Иногда нужно, чтобы MacBook продолжал работать с закрытой крышкой — например, пока Cursor или другая программа долго что-то считает. Обычный «не давать уснуть» (`caffeinate` и похожие) крышку не держит: Mac всё равно засыпает. Это приложение выключает системный сон на время, гасит экран при закрытии крышки и само возвращает обычный сон, когда время вышло, батарея села или программа упала.

**Что показывает.** В строке меню: температура чипа, загрузка процессора и занятая память. По клику — панель с переключателем «Не спать», длительностью, батареей и причиной последнего автоотключения.

Без сети, без телеметрии, без значка в Dock, без автозапуска приложения при входе.

Требования: macOS 14+, Apple Silicon (проверено на MacBook Air M5, macOS 27).

---

## Быстрый старт

**Готовый файл.** Откройте `NeSpat-1.0.dmg` → перетащите `NeSpat.app` в Applications → правый клик → Открыть. В строке меню появятся цифры.

**Из исходников:**

```bash
./scripts/build.sh --install
open ~/Applications/NeSpat.app
```

При включении «Не спать» macOS спросит пароль администратора. Постоянных правил sudoers приложение не создаёт.

## Как пользоваться

| В строке меню | Значение |
|---|---|
| `☕ 52° 18% 69%` | Режим включён и подтверждён системой |
| `52° 18% 69%` | Обычный сон |
| `⚠ …` | Состояние сна не удалось подтвердить |

Длительность: без ограничения / 1 ч / 3 ч / 8 ч. Обычный сон возвращается автоматически:

- кончился срок;
- заряд ниже 15% при питании от батареи;
- перегрев (тепловой режим системы или температура чипа ≥ 95 °C);
- выход из приложения (если режим включали вы);
- падение приложения — через сторожа (см. ниже).

Если сон выключен не этим приложением, панель честно пишет об этом и предлагает вернуть обычный сон кнопкой. Чужой флаг при «Выход» молча не снимается.

При закрытой крышке во время режима экран гасится (`pmset displaysleepnow`), сам Mac продолжает работать.

## Сторож (по желанию)

LaunchAgent, который раз в 30 с проверяет: если режим наш, а приложение не запущено — вернуть обычный сон. Это не автозапуск приложения, только страховка.

```bash
./scripts/install-watchdog.sh
```

Журнал: `~/Library/Logs/NeSpat/watchdog.log`.

---

## Передача другому Mac

```bash
./scripts/package-dmg.sh   # → build/NeSpat-1.0.dmg
```

На другом Mac: открыть DMG → Applications → при первом запуске «Открыть» через правый клик (подпись ad-hoc). Сторож ставится отдельно из исходников, если нужен.

---

## Удаление

```bash
./scripts/uninstall.sh                 # приложение, сторож, файлы; сон — если сессия наша
./scripts/uninstall.sh --force-sleep   # то же + гарантированно вернуть сон
```

Данные: `~/Library/Application Support/NeSpat/`, логи: `~/Library/Logs/NeSpat/`.

---

## Технические детали

- Сон: `pmset -a disablesleep 1|0`. Подтверждение — через IOKit (`IOPMrootDomain.SleepDisabled`); `caffeinate` не используется.
- Температура: HID-датчики `PMU tdie*` (температура кристалла, не корпуса). Если датчиков нет — «—».
- CPU: `host_processor_info`. Память: `host_statistics64` (active + wired + compressed). Батарея: IOPowerSources.
- Проверка из терминала: `NeSpat.app/Contents/MacOS/NeSpat --print-stats`.

Не оставляйте работающий Mac в сумке: с выключенным сном он продолжает греться. У Air нет вентилятора — держите нормальную вентиляцию.
