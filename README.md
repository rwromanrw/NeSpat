# Не спать (NeSpat)

Небольшое приложение для строки меню macOS.

**Зачем.** Иногда нужно, чтобы MacBook продолжал работать с закрытой крышкой — например, пока Cursor или другая программа долго что-то считает. Обычный «не давать уснуть» (`caffeinate` и похожие) крышку не держит: Mac все равно засыпает. Это приложение выключает системный сон на время, гасит экран при закрытии крышки и само возвращает обычный сон, когда время вышло, батарея села или программа упала.

**Что показывает.** В строке меню: цветная чашка статуса + температура чипа, загрузка процессора и занятая память. По клику — панель с переключателем «Не спать», длительностью и метриками: у каждой насыщенная шкала, где длина заливки — значение, а цвет — состояние (зеленый/желтый/красный). Там же батарея, причина последнего автоотключения и сколько Mac реально не спал под закрытой крышкой в прошлый раз.

Без сети, без телеметрии, без значка в Dock. Автозапуск при входе — по желанию, переключателем в панели.

Требования: macOS 14+, только Apple Silicon (проверено на MacBook Air M5, macOS 27). Лицензия: MIT (см. [LICENSE](LICENSE)).

## Быстрый старт

Готовый установщик: **[скачать NeSpat-1.0.dmg](https://github.com/rwromanrw/NeSpat/releases/download/v1.0/NeSpat-1.0.dmg)**  
Страница релиза: https://github.com/rwromanrw/NeSpat/releases/v1.0

1. Скачайте `NeSpat-1.0.dmg`, откройте и перетащите `NeSpat.app` в папку Applications.
2. В Finder → Программы найдите «Не спать».
3. **Первый запуск.** Приложение не из App Store и без нотаризации Apple — это нормально для открытого проекта. Правый клик по «Не спать» → **Открыть** → в диалоге снова **Открыть**. Обычный двойной клик macOS может блокировать.
4. В строке меню появятся цифры. Готово.

Обновления: новый DMG в [Releases](https://github.com/rwromanrw/NeSpat/releases) — замените приложение в Applications.

**Из исходников (для разработчиков):**

```bash
./scripts/build.sh --install
open /Applications/NeSpat.app
```

Скрипт ставит одну копию в `/Applications` (если есть права) или в `~/Applications`.

**Пароль администратора.** И включение, и выключение режима меняют системный флаг сна (`pmset disablesleep`). macOS спрашивает пароль на оба действия. Постоянных правил sudoers приложение не создает.

В панели: переключатель **«Запускать при входе»** и кнопка **«Мониторинг системы»** (открывает Activity Monitor).

Позиция в строке меню: зажмите **⌘** и перетащите пункт куда удобно — после перезапуска macOS запомнит место.

## Как пользоваться

В строке меню — чашка и цифры (`52° 18% 69%`). Цвет чашки:

| Чашка | Значение |
|---|---|
| Зеленая | Режим включен и подтвержден системой |
| Серая | Обычный сон |
| Желтая | Сон выключен не этим приложением |
| Красная | Состояние сна не удалось подтвердить |

Длительность: без лимита / 1 ч / 3 ч / 8 ч. Обычный сон возвращается автоматически:

- кончился срок;
- заряд ниже 15% при питании от батареи;
- перегрев (тепловой режим системы или температура чипа ≥ 95 °C);
- выход из приложения (если режим включали вы);
- падение приложения — через сторожа (см. ниже).

Режим работает и от батареи, и на зарядке. Зарядка не обязательна; на батарее при заряде ниже 15% режим сам выключится.

Если сон выключен не этим приложением, панель честно пишет об этом и предлагает вернуть обычный сон кнопкой. Чужой флаг при «Выход» молча не снимается.

При закрытой крышке во время режима экран гасится (`pmset displaysleepnow`), сам Mac продолжает работать.

### Сколько не спал под крышкой

После открытия крышки в панели появляется строка вроде `Прошлый раз под крышкой: 7 ч 42 мин` — сколько Mac реально не спал с прошлого закрытия (по «сердцебиению» приложения, а не просто по часам на стене).

- Надпись остается после выключения режима и после таймера — можно глянуть утром или позже.
- Сбрасывается только при следующем закрытии крышки, пока «Не спать» снова включен (тогда идет новый замер).

## Сторож (по желанию)

LaunchAgent, который раз в 30 с проверяет: если режим наш, а приложение не запущено — вернуть обычный сон. Это не автозапуск приложения, только страховка.

```bash
./scripts/install-watchdog.sh
# или явно: ./scripts/install-watchdog.sh /Applications/NeSpat.app
```

Скрипт сам находит приложение в `/Applications` или `~/Applications`. Журнал: `~/Library/Logs/NeSpat/watchdog.log`.

Если режим был включен и приложение упало, сторож вернет обычный сон. Без правила sudoers macOS может один раз спросить пароль администратора — это нормально.

В **Настройки → Основные → Объекты входа и фон** могут быть две строки NeSpat: само приложение и сторож. Сторож не висит постоянно — коротко просыпается раз в 30 с.


На другом Mac: открыть DMG → Applications → при первом запуске «Открыть» через правый клик (подпись ad-hoc). Сторож ставится отдельно из исходников, если нужен.

## Удаление

```bash
./scripts/uninstall.sh                 # приложение (/Applications и ~/Applications), сторож, файлы; сон — если сессия наша
./scripts/uninstall.sh --force-sleep   # то же + гарантированно вернуть сон
```

Данные: `~/Library/Application Support/NeSpat/`, логи: `~/Library/Logs/NeSpat/`.

## Технические детали

- Сон: `pmset -a disablesleep 1|0`. Подтверждение — через IOKit (`IOPMrootDomain.SleepDisabled`); `caffeinate` не используется.
- Температура: HID-датчики `PMU tdie*` (температура кристалла, не корпуса). Если датчиков нет — «—».
- CPU: `host_processor_info`. Память: `host_statistics64` (active + wired + compressed). Батарея: IOPowerSources.
- Строка меню: SwiftUI `MenuBarExtra` + `MenuBarExtraAccess`; чашка — цветная `NSImage` (не template), цифры рядом.
- Замер под крышкой: старт при закрытии, heartbeat каждые 5 с, итог при открытии; хранится в `session.json` до следующего закрытия.
- Проверка из терминала: `NeSpat.app/Contents/MacOS/NeSpat --print-stats`.

Не оставляйте работающий Mac в сумке: с выключенным сном он продолжает греться. У Air нет вентилятора — держите нормальную вентиляцию.
